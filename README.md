# Inversiones MDS · App de Clientes

Ecosistema de la marca para clientes Mindray: tienda, servicio técnico, academia, eventos, asesor IA y programa de puntos. PWA (React + Vite + TypeScript).

```bash
npm install
npm run dev
```

- Esquema de base de datos: `supabase/schema.sql`
- Hoja de ruta: `ROADMAP.md`
- Estado actual: datos de ejemplo guardados en el navegador (sin backend todavía).
